# Jev 驱动的房间空间关系求解（设计草案）

日期：2026-09-19。状态：已实现实验性 v2 求解闭环，尚未替换默认旧算法；真实样本未达到可用标准。

## 目标与职责

从 Room Seed 识别空间范围，同时输出可复查的边界、内部障碍物、开口关系和未决问题。成功必须同时满足几何有效与 Jev 语义接受；面积接近或闭合不能单独表示成功。

Jev 决定对象身份、空间分隔/连通关系、标注归属和最终候选。几何负责实测证据、可执行候选、拓扑构建和校验。预算策略决定何时停止取证，不得替代语义决策。

## 当前实现的结构问题

- `src/jev-room-traverse.ts` 的 final 分支直接接受 face-walk 候选，绕过 Jev；面积最接近成为隐含语义裁决。
- `src/room-layer-filter.ts` 会改写模型的 exclude；图层内混合用途和模型判断冲突没有作为问题交还模型。
- `src/room-traversal.ts` 将 seed-side-inconsistent 作为硬排除。凹形房间不要求同一个内部点位于所有有向边的同侧。
- 面积文字按最近距离关联，输入 Jev 前已隐含决定文字属于目标房间。
- 原子对象和 CAD 父图元并不等价。禁止重复父对象虽能阻止绕圈，也可能排除合法路径；一个长墙或多段线可在房间边界上贡献多个不同区段。
- 当前新房间使用 provisional walls，旧房间使用过分组/分段的墙；不能把结果差异全部归因于算法。

## 推荐算法：空间关系驱动的候选与取证循环

### 1. 建立可追溯的局部证据

统一 CAD 单位和坐标，展开 Block Definition 与实例变换，保留原始父子关系。缺少块定义时记录几何未知，不从 INSERT 缩放量直接推断柱子尺寸。

上下文以 Analysis Window 表达，包含目标文字、邻室文字、候选对象、图层统计和跨窗口连接。按真实几何范围检索，而非只按插入点或中心距离。窗口边缘未完成的连接允许触发扩大取证；达到预算后返回 incomplete。

压缩重复、共线几何时保留来源映射；误差容限按图纸单位明确配置。无法确认的相交/吸附连接是候选假设，不直接成为真实建筑连接。

### 2. Jev 解释对象和空间意图

模型首先判断文字归属、目标空间类型以及候选对象关系：封闭房间、开放功能区或证据不足。开放功能区可输出未确定的空间范围，不能为满足闭合强行补墙。

图层只用于检索优先级和证据组织。一个图层可以混有墙、装修和符号；层级结论不自动覆盖对象级结论。发生冲突时形成包含双方证据的 choice 问题，由 Jev 保留、修正或置为未知。

保留 linear/object/opening 作为几何表示方式，但它不等于“参与房间边界”。柱子既可能参与外轮廓，也可能是房内障碍物；门既有可通行性，也可能需要虚拟边来划分两个房间。

### 3. 将选择题放在有意义的空间关系上

几何生成候选接触面、门窗两侧接点、对象轮廓路径和相邻空间片段。每个选择项绑定稳定 ID、完整几何后果及来源，不允许模型随意生成坐标。

问题按实际歧义构造，例如：

- 这组图元：同一物理对象 / 不同对象 / 证据不足。
- 此对象表面：分隔目标空间 / 属于内部障碍物 / 绘图表达线 / 无关 / 未知。
- 此开口两侧：同一房间连续 / 不同房间的通行连接 / 外窗边界 / 未知。
- 此断口：采用候选 A 的现有连接 / 候选 B 的开口封口 / 扩大上下文 / 全部不成立 / 未知。
- 此面积文字：属于目标空间 / 属于邻室 / 无法关联。

每次请求都包含同一份紧凑全局上下文，以及本题局部详细证据。避免把候选分批后丢掉共同参照。模型可以选择没有合适候选，不能被迫从错误列表中择优。

先以现有结构化 choice 请求实现；模型是否支持图像、输出概率是否可校准，需单独验证，不作为设计前提。

### 4. 几何构建空间候选

从对象表面构建带方向的平面图；face walking 是提取几何空间片段的工具，不承担房间语义识别。

在分隔关系已经明确的图上提取候选空间。残余绘图线可能将同一房间分割成多个 face；仅在 Jev 判断为非分隔或同空间连续时合并相邻片段。门洞的可通行连通不等于房间合并。

存在未决关系时，保留少量互斥图假设，每个假设单独构图和验证，不把所有可能的虚拟边同时当真。合并片段后重新计算外环、内环及完整来源。

输出允许一个外环加内部障碍物/孔洞；面积分别报告外环面积与扣除障碍物的面积，避免未知计量口径影响候选选择。不得把所有封闭对象都当作房间外轮廓。

若候选中不存在合理房间，返回缺口、窗口截断或关系冲突，进入局部取证；不能只在现有 top-k 内反复挑选。

### 5. 将计算预算用在关键未决关系

优先询问会改变空间连通、吸收邻室、改变轮廓或决定断口是否闭合的问题。这个优先级只安排请求，不自动决定答案。

距离、转角、seed 侧向和面积差用于候选排序和模型证据，不作为一般语义硬过滤。硬排除仅针对已证明的几何不可能，例如非法自交或重复消费同一有向区段；容限吸附必须显式记录。

连续同对象路径仍可压缩为 transition；禁止重复消费同一几何区段，而非一律禁止再次出现同一个 CAD 父 ID。已有 `3E0207` 测试保留为具体预期，不能提升为所有图纸的全局公理。

面积证据只有在归属和计量口径可用时才参与比较。开放路径临时封口得到的面积不是最终面积的单调下界，不用它提前淘汰所有后续扩展。

### 6. 完整候选交给 Jev 裁决

无论只有一个还是多个候选，都必须通过 Jev 的 accept / reject_all / insufficient_evidence 判断。

请求包含候选空间摘要、邻室包含关系、完整有序轮廓的紧凑表示、障碍物、每项虚拟连接、支持和冲突证据。完整高精度路径在本地保存并用于校验；请求压缩不得省略会改变拓扑的弯折和开口。无法在请求预算内完整表达关键证据时继续分层取证或返回未决。

超时、token 超限或低置信度均不能触发确定性替代接受。保存请求、原始响应、模型版本、候选集合和输入 hash，支持离线回放；模型置信度不当成已校准准确率。

## Module 与 Interface

对外保留一个深模块 `RoomBoundaryResolver`，接收图纸上下文、Room Seed、预算与决策 adapter，返回 accepted / incomplete / uncertain 及证据轨迹。调用方不需要编排 layers、portals、beam 和 faces。

内部划分三项职责：证据与几何模块、Jev 决策模块、候选及取证循环。模型调用的 seam 提供实时 Jev adapter 和保存响应的 replay adapter，几何测试无需联网。

accepted 必须同时有完整几何校验和最终 Jev 决策。incomplete 表示证据或几何构建尚未完成；uncertain 表示当前证据无法支持明确语义选择。候选多边形可以显示，但不因可视化填充而被标记为成功。

## 验证方式

已有四个房间作为开发诊断集，不作为泛化证明。选择其他区域及其他图纸的留出样本，在查看结果前固定规则、预算和预处理；测试期间不按 handle、房间名或图层名加特例。

由人工确认目标边界、内部障碍物、开放区与允许的不确定性。衡量边界偏差、邻室误吞、错误接受率、未决比例、候选召回率、模型请求量与耗时。面积误差仅是辅助指标。

加入合成形状与扰动验证：凹形房间、内部柱子、柱子参与外轮廓、门洞、双线窗、断线、无面积标注；同一几何平移旋转、实体顺序变化、等价分段、图层改名、添加无关标注后，检查结构结果稳定性和模型差异。

保留消融对比：纯几何候选、Jev 关系判断、Jev 最终裁决、完整取证循环。区分候选没生成、关系判错和最终选错，避免所有失败都归因于模型或都交给几何补丁。

## 逐步迁移

1. 固定现状输入、预处理和原始模型轨迹；建立统一回放与失败分类。
2. 恢复所有路径的 Jev 最终裁决；取消静默改写决策，增加冲突复核与 reject_all。先确保 accepted 的含义可信。
3. 校正对象几何与 provenance，引入真实块轮廓、区段身份和空间关系选择题。
4. 在同一 Interface 下实现关系驱动的 face 提取/合并及内环表达，以实验策略与旧算法并行比较。
5. 接入按缺陷局部扩窗和未决关系取证；预算耗尽明确返回失败类型。
6. 在固定留出集上比较正确性、错误接受率和成本，再决定替换旧算法。

## 实施记录（2026-09-19）

- 已实现最终裁决模块与 live/replay adapter，旧入口恢复 Jev 最终判断；原始交换及代码/输入哈希持久化。资料室历史误接受候选经 Jev 实际复核被拒绝。
- 已实现独立 `room-resolve` 实验入口，所有样本共用同一 DXF 实测几何、同一检索预算。块实例真实展开；原始 CAD IR 不变。旧路径的简化柱轮廓仍保留用于历史对照，不能混为 v2 的输入。
- 已实现房间类型、标注归属、图元级空间关系、开口/断口连接的 Jev 选择题；模型接受后才生成分隔图或虚拟连接。没有把图层结论硬用于新图。
- 已实现 face 提取、移除同空间内部表达线后重新构图、障碍物内环及区段连续性/复用/自交检查。按缺口扩大上下文；请求过大时拆题，保留共同上下文。
- 已运行合成回归与六个同图纸真实房间。结果及原始模型响应位于 `reports/room-v2/evaluation/`；未通过的结果保留 incomplete/uncertain，不输出 accepted。

表面复核迭代：已增加失败后的区段级 Jev 选择，支持同一父图元中部分保留、部分删除，并可恢复此前未选区段；障碍物冲突会触发带具体缺陷的复核。候选仍受检索预算限制，不等于全部表面都已解决。新评测保存在 `reports/room-v2/surface-final/`，最终仍为 0/6 接受。

仍未完成的设计项：完整表面关系覆盖、跨实体物理对象身份确认、完整互斥连接假设搜索、开放功能区范围求解、跨图纸人工标注留出集和完整消融评估。当前 v2 是可回放实验实现，不能宣布全部设计已完成或泛化有效。

旧模块仍有 seed 侧向硬过滤、图层 effective policy、原子父对象限制等历史策略；v2 不经过这些策略。迁移是否成功以评测为准，不能因为创建了新入口就默认替换旧实现。

联合修补迭代：新增端点到墙段内部的投影候选，以及最多两个虚拟连接的完整轮廓组合；Jev 接受完整候选才批准其连接。已闭合但被拒绝的候选也会触发下一轮修补搜索。六房间最终回归仍为 0/6 接受，所有决策命中精确证据缓存；限制和结果见 `docs/room-joint-repair-results.md`，不能据此声称泛化或识别效果提升。

后续多断口实验：在同一 96 变体预算内加入多连接兼容集合，取消仅能提出双断口方案的限制；搜索非穷举，并修复虚拟连接被分割后的批准证据遗漏。57 项测试通过，六房间仍为 0/6 接受。详见 `docs/room-multi-gap-results.md`。

区段召回诊断：确认复杂已排除图元挤占复核名额，改为当前图/恢复候选分配预算并按 Source Entity 轮换；同一 48 段预算下六房间当前图区段复核总量从 120 提高至 192。新增 45 次 Jev 调用，实际移除 21 段、补回 1 段，但最终仍为 0/6 接受。诊断脚本和限制见 `docs/room-source-balanced-results.md`。

断口检索迭代：第二轮在固定预算内按断口轮换检索，并向 Jev 提供邻接已选边界的实际区段。冷链室 1500mm 范围内的新增图元覆盖由 13/15 提高到 15/15，资料室生成 2.780㎡候选但被拒绝。63 项测试通过；新增 81 次模型请求，六房间仍为 0/6 接受。详见 `docs/room-frontier-results.md`；这尚未实现整组关系联合决策或正确边界召回验证。


结构候选接续验证（2026-09-19）：修复局部结构池忽略障碍物而错误接受的路径，移除总对象数门槛，采用独立的结构对象/区段预算，并将所有候选区段及历史关系交给最终 Jev 裁决。70 项测试与类型检查通过；固定六房间新增 37 次请求，最终仍为 0/6 接受。详见 `docs/room-structural-hypotheses-results.md`。
