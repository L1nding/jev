# Triage labels

| Role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue. |
| `needs-info` | `needs-info` | Work is waiting for more information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and can be implemented autonomously. |
| `ready-for-human` | `ready-for-human` | The issue requires human judgment or manual review. |
| `wontfix` | `wontfix` | The issue will not be actioned. |
