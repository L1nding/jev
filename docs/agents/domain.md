# Domain documentation

This is a single-context repository.

Before changing CAD interpretation or room-boundary behavior:

1. Read `CONTEXT.md` for canonical terms.
2. Read the relevant records under `docs/adr/`.
3. Use the canonical terms in code, tests, documentation, and issue titles.
4. Surface conflicts with an ADR explicitly. Do not silently replace its decision.

`CONTEXT.md` is a glossary, not an implementation specification. Architectural decisions belong in `docs/adr/`; implementation and evaluation details belong in the other documents under `docs/`.
