# Resolve rooms from one candidate-first boundary graph

Room resolution will enumerate complete Candidate Boundaries from one Candidate Boundary Graph before asking Jev to compare them. Boundary Surfaces, room-area evidence, opening portals, and deterministic topology constrain retrieval and validation, while Jev remains the final semantic authority. This supersedes the step-by-step traversal requirement in ADR-0003 because independent object decisions and repairs on an already filtered graph repeatedly lost the correct enclosure; ADR-0003's requirements for explicit Virtual Boundary Edges, traceability, and Jev-owned acceptance remain in force.
