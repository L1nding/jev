# Repository guidance

Use the domain vocabulary in `CONTEXT.md` and preserve the decision authority recorded in `docs/adr/`.

## Agent skills

### Issue tracker

Issues are tracked in this repository's GitHub Issues with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` at the root and architectural decisions in `docs/adr/`. See `docs/agents/domain.md`.
